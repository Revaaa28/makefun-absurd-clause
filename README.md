## The Clause

> The company may borrow your body on alternate Tuesdays, returning it washed, folded, and no more than three percent (3%) haunted.

## The Joke

The humor comes from deadpan legal boilerplate: the sentence is written like an ordinary terms-of-service clause, complete with a precise percentage in parentheses, while quietly granting the company the right to borrow your body on alternate Tuesdays and return it washed and folded — with only a small, contractually tolerated amount of haunting.

## How to run

```bash
python3 main.py
```

This writes `/output/entry.txt` containing the single-sentence clause. Set the `OUTPUT_DIR` environment variable to override the target directory:

```bash
OUTPUT_DIR=/tmp/out python3 main.py
```
